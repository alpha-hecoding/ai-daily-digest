## 🤖 二、Agent 架构与范式

### 1. AI4AI-Bench：递归自我改进能力的基准测试

**研究背景**：
递归自我改进（RSI）是AI领域的"圣杯"问题：一个AI系统能否改进产生AI系统的过程本身？本研究提出了AI4AI-Bench，首个专门测试Agent设计训练算法能力的基准。

**核心发现**：
| 指标 | 结果 |
|------|------|
| 任务数 | 10个冻结的研究仓库 |
| 时间限制 | 4小时设计 + 12小时运行 |
| 最佳系统得分 | 0.250（满分1.0） |
| 平均得分 | 0.166 |
| 改进学习方式的提交占比 | 8% → 64%（增加推理努力后） |

**研究方法**：
1. **任务定义**：10个不同的训练算法任务，涵盖不同家族
2. **评估机制**：固定评估器隐藏于Agent之外，确保公平
3. **评分标准**：0=无信息模型，0.1=原始算法，1.0=最优

**关键洞察**：
- **大部分Agent没有改变模型学习方式**：只做了超参数调优
- **愿意修改核心算法的Agent表现更好**：平均0.226 vs 0.126
- **更多推理时间带来质的飞跃**：愿意修改核心算法的提交从8%增至64%

**💡 对你的价值**：
- 如果你正在构建Agent系统，这个基准可以帮助你评估其"元学习能力"
- 说明了当前LLM在算法设计上的局限性：即使最强模型也只完成了最优解的1/5
- 未来方向：构建能真正理解并改进训练过程的Agent

**相关链接**：
- 论文：[arXiv:2608.20318](https://arxiv.org/abs/2608.20318)
- 基准代码：即将开源

### 2. 多智能体工作流：旅行行为预测的Agent实践

**研究背景**：
传统的数据收集和预测建模往往分离处理。本研究提出了一种三Agent工作流，将对话式数据收集、结构化数据处理和行为预测整合为一个可审计的多智能体系统。

**技术架构**：

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   Agent 1       │────▶│   Agent 2       │────▶│   Agent 3       │
│ 对话式数据收集  │     │ 结构化数据处理  │     │ 行为预测        │
│ (图像增强调查)  │     │ (特征工程)      │     │ (LLM+ML)        │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**核心发现**：

| 方法 | 五分类准确率 | 备注 |
|------|--------------|------|
| Random Forest | 69.6% | 传统ML基准 |
| 最佳文本零样本LLM | 69.9% | 无任务特定微调 |
| 最佳视觉配置LLM | 71.5% | 加入天气图像 |

**关键设计决策**：
1. **习惯性出行信息**：最一致的增益来源
2. **专家框架 vs 角色扮演**：专家框架通常更优
3. **Persona信息**：在习惯信息不可用时最有用
4. **Few-shot**：少量示例后性能稳定

**💡 对你的价值**：
- **可审计性**：多Agent架构让每个决策都可追溯
- **多模态融合**：视觉信息提供了额外的预测信号
- **实用启示**：设计Agent时，优先注入用户习惯数据

**相关链接**：
- 论文：[arXiv:2608.20320](https://arxiv.org/abs/2608.20320)

### 4. IAR框架：文档知识内化的三阶段方法

**研究背景**：
LLM在没有检索增强的情况下，往往无法回答特定文档集合的问题。本研究提出了IAR（Inject-Align-Recover）框架，解决"文档知识内化"问题。

**三阶段流程**：

```
┌─────────────────────────────────────────────────────────────┐
│                     IAR 框架                                 │
├─────────────┬─────────────┬─────────────────────────────────┤
│   Inject    │    Align    │           Recover               │
│ 知识注入    │  行为对齐   │         能力恢复                │
│ 文档→训练   │  QA监督     │    与基础模型合并               │
└─────────────┴─────────────┴─────────────────────────────────┘
```

**核心发现**：

| 模型家族 | 领域QA提升 | 通用性能变化 |
|----------|------------|--------------|
| Llama | +3.6% | +12.1% |
| Phi | +4.2% | +10.8% |
| Qwen | +3.1% | +13.5% |
| SmolLM | +3.9% | +11.7% |

**技术创新**：
1. **Inject阶段**：将文档转化为续写、重写、指令条件重建目标
2. **Align阶段**：仅使用答案监督（非完整问答对）
3. **Recover阶段**：与基础指令模型合并，恢复通用能力

**💡 对你的价值**：
- 如果你有特定领域的文档需要"注入"到模型中，IAR提供了系统方法
- 相比传统SFT，IAR在领域性能和通用能力之间取得了更好平衡
- 建议：先用小规模文档验证，再扩展到完整文档集

**相关链接**：
- 论文：[arXiv:2608.20281](https://arxiv.org/abs/2608.20281)
