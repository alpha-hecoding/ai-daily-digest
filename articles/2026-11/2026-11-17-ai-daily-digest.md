### 2.1 MIRIX-2.0：多智能体记忆系统

**论文热度**：3.48k 阅读，HuggingFace Daily Papers 热门
**作者团队**：5 人团队

#### 核心创新

MIRIX-2.0 提出了一个面向多智能体系统的统一记忆框架，解决了现有 Agent 系统在长期记忆、知识共享、上下文保持方面的痛点。

**三大记忆模块**：

1. **工作记忆（Working Memory）**
   - 短期上下文保持
   - 任务相关的临时状态
   - 自动过期机制

2. **情景记忆（Episodic Memory）**
   - 历史交互记录
   - 可检索的经验片段
   - 支持相似度搜索

3. **语义记忆（Semantic Memory）**
   - 结构化知识存储
   - 跨 Agent 知识共享
   - 持续学习与更新

#### 架构设计

```
┌─────────────────────────────────────────┐
│              MIRIX-2.0                  │
├─────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐ │
│  │ Agent A │  │ Agent B │  │ Agent C │ │
│  └────┬────┘  └────┬────┘  └────┬────┘ │
│       │            │            │       │
│  ┌────▼────────────▼────────────▼────┐  │
│  │        Memory Router              │  │
│  └────┬────────────┬────────────┬────┘  │
│       │            │            │       │
│  ┌────▼────┐  ┌────▼────┐  ┌────▼────┐  │
│  │Working  │  │Episodic │  │Semantic │  │
│  │Memory   │  │Memory   │  │Memory   │  │
│  └─────────┘  └─────────┘  └─────────┘  │
└─────────────────────────────────────────┘
```

3. **个人助理集群**：日程、邮件、笔记 Agent 协同工作

### 2.2 Agent-as-a-Judge：用 Agent 评估 Agent

**论文**：Agent-as-a-Judge
**项目页**：github.com/ModalityDance/Awesome-Agent-as-a-Judge

#### 核心理念

传统 Agent 评估依赖人工标注或固定基准测试，成本高且难以覆盖真实场景。Agent-as-a-Judge 提出用 Agent 来评估 Agent，实现自动化、可扩展的质量评估。

#### 评估框架

```
┌─────────────────────────────────────────┐
│           Agent-as-a-Judge              │
├─────────────────────────────────────────┤
│                                         │
│  ┌──────────┐      ┌──────────────┐    │
│  │ Target   │ ───▶ │  Judge Agent │    │
│  │ Agent    │      │  (Evaluator) │    │
│  └──────────┘      └──────┬───────┘    │
│                           │            │
│                    ┌──────▼───────┐    │
│                    │  Evaluation  │    │
│                    │   Report     │    │
│                    └──────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

#### 评估维度

1. **任务完成度**：是否正确完成指定任务
2. **效率指标**：步骤数、时间、资源消耗
3. **质量指标**：输出准确性、一致性
4. **安全指标**：是否触发危险操作

#### 💡 对你的价值

在 Agent 系统上线前，用 Judge Agent 进行自动化测试可以大幅降低人工评估成本。特别适合回归测试和持续集成场景。
